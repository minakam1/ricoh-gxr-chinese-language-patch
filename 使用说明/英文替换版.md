# 水水固件 · 英文替换版使用说明

## 基本信息

- 项目名称：Ricoh GXR 1.51 水水固件
- 发布版本：英文替换版
- 适用设备：Ricoh GXR 机身及 GXR 相机模块
- 目标固件：更新至 1.51
- 文件名称：`Ricoh_GXR_1.51_水水固件_英文替换版.zip`

本项目仓库及唯一发布地址：

<https://github.com/minakam1/ricoh-gxr-chinese-language-patch>

请只从该仓库的 GitHub Releases 下载并核对 SHA-256，不要使用商业网站、网店、
收费渠道或来历不明的转载包。

## 作用

本包包含完整的 Ricoh GXR 1.51 升级文件，可以把较旧版本的机身及当前连接的
相机模块更新到 1.51。刷写后：

- `日本語` 保持日文；
- 选择 `English` 时显示简体中文。

恢复官方 1.51 后，English 会恢复为英文。

## SD 卡内容

`SD_ROOT` 内共有 29 个文件。必须全部复制到 SD 卡根目录，不能只复制
`ilaunch3`，也不能把 `SD_ROOT` 文件夹本身复制到卡中。

## 更新步骤

1. 备份 SD 卡内的照片。
2. 使用满电电池，将需要更新的相机模块安装到机身。
3. 在相机中格式化一张容量不小于 64 MB 的 SD 卡。
4. 将本包 `SD_ROOT` 内的全部 29 个文件复制到 SD 卡根目录。
5. 安全弹出 SD 卡或相机磁盘，断开 USB，确认相机关机。
6. 按住 `+` 按钮，同时按住回放按钮 2–3 秒。
7. 出现更新确认画面后，用 Fn2 选择“是”，按 MENU/OK。
8. 等待相机完成更新并自动重启。期间不要断电、拔卡或拆卸相机模块。
9. 进入语言设置，选择 `English`，界面应切换为简体中文。

如果拥有多个相机模块，请按理光官方要求，为每个模块分别安装并执行一次更新。
