# 水水固件研究资料

这里保存 Ricoh GXR 1.51 语言机制、调试系统和内部存储研究中可公开复核的程序与
结果，便于继续研究和验证。

## 目录

- `工具/只读分析`：读取固件结构、资源、调试表和存储镜像，不修改输入文件。
- `工具/实验构建`：重现语言补丁和地区解锁实验的构建逻辑。
- `报告`：各阶段逆向、真机观察与技术结论。
- `结构化结果`：分析器输出的 JSON 和 CSV，便于检索或二次处理。

## 使用边界

仓库不包含机身内部存储镜像、照片、序列号、个人配置备份、候选 KEY 文件、官方
固件原包或失败实验刷机包。

`工具/实验构建` 中的脚本用于审计和复现实验过程，不代表生成物已经适合任何机身。
除 GitHub Releases 中明确发布的水水固件外，不要把研究目录中的脚本输出直接刷入
相机。修改固件和调整数据可能造成无法开机、校准异常或数据丢失。

本研究资料仅供学习研究，如有侵权请联系作者删除。禁止商业分发或商业利用。
