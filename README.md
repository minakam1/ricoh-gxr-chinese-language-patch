# Ricoh GXR 1.51 水水固件修改器

本项目为 Ricoh GXR 1.51 提供两种语言修改方案。修改器读取用户准备的官方固件，
在本地完成检查、修改和重新打包，项目仓库与 Release 只发布修改工具。

项目仓库及发布地址：

<https://github.com/minakam1/ricoh-gxr-chinese-language-patch>

请从上述仓库下载修改器并核对随包提供的 SHA-256。其他网站、网盘或收费渠道中的
副本可能已经被改动。

## 两种修改模式

| 模式 | 效果 | 是否持久 | 适合用途 |
|---|---|---|---|
| **1 · 英文替换版** | 语言菜单仍显示 `日本語 / English`，选择 `English` 后显示简体中文 | 依赖修改固件 | 只需要简体中文，操作最直接 |
| **2 · 完全解锁版** | 语言菜单开放全部 11 种语言 | 写入机身地区设置，恢复官方固件后仍然保留 | 需要解除日版语言限制 |

两种模式生成的都是完整升级包，可以把较旧版本的 GXR 机身及当前连接的相机模块
更新到 1.51；机身已经是 1.51 时，也可以再次执行更新。

> 这是非官方修改工具。开始操作前请读完刷写步骤和风险说明，并准备好官方 GXR
> 1.51 固件作为输入及恢复包。

## 下载修改器

前往 [最新 Release](https://github.com/minakam1/ricoh-gxr-chinese-language-patch/releases/latest)：

- Windows：`GXR固件修改器-Windows.zip`
- Apple 芯片 Mac：`GXR固件修改器-macOS-arm64.zip`

Windows 版由 `.bat` 和 PowerShell 脚本组成，使用系统自带的 PowerShell，不需要
安装 Python，也不需要 EXE。macOS 版已经打包好运行环境，同样不需要安装 Python。

## 使用前准备

先下载 Ricoh GXR 1.51 官方固件：

- [官方 ZIP 直链](https://www.ricoh-imaging.co.jp/english/r_dc/download/firmware/exe/gxr-151.zip)
- [Ricoh GXR 官方固件页面](https://www.ricoh-imaging.co.jp/english/r_dc/download/firmware/gxr/)

然后准备以下内容：

1. 上述官方固件 ZIP，或者解压后的官方固件文件夹。
2. 给相机电池充满电，备份 SD 卡中的照片。
3. 保留一份未经修改的官方 GXR 1.51 固件，用于恢复。
4. 如果有多个相机模块，升级和恢复时需要分别连接每个模块操作。

修改器会核对官方升级包中的 29 个文件。检查通过后才会进入模式选择，原始固件
不会被覆盖，生成结果保存在原固件旁边。

## Windows 操作方法

1. 解压 `GXR固件修改器-Windows.zip`。
2. 完整解压后，保持 `GXR固件修改器.bat` 和 `gxr_modifier.ps1` 在同一文件夹中。
3. 把官方固件 ZIP 或解压后的固件文件夹拖到 `GXR固件修改器.bat` 上。
4. 检查通过后输入 `1` 或 `2`，按回车确认。
5. 等待窗口显示“生成完成”，记下绿色的输出路径。

## macOS 操作方法

1. 解压 `GXR固件修改器-macOS-arm64.zip`。
2. 把官方固件 ZIP 或解压后的固件文件夹拖到
   `运行_GXR固件修改器.command` 上。
3. 检查通过后输入 `1` 或 `2`，按回车确认。
4. 等待终端显示“生成完成”，记下绿色的输出路径。

如果系统首次运行时提示无法验证开发者，请在“系统设置 → 隐私与安全性”中确认打开。

## 输出文件

修改器会根据所选模式生成：

```text
Ricoh_GXR_1.51_水水固件_英文替换版.zip
Ricoh_GXR_1.51_水水固件_完全解锁版.zip
```

同名文件已经存在时，新文件会自动追加 `_2`、`_3` 等编号。每个 ZIP 内均包含中文
说明、构建信息，以及可以复制到 SD 卡的 `SD_ROOT` 目录。

## 英文替换版

英文替换版适合只想使用简体中文界面的用户：

- 日本语入口保持正常；
- `English` 入口改为简体中文；
- 其他 28 个官方升级文件保持原样；
- 恢复官方 GXR 1.51 后，`English` 会恢复为英文。

刷写完成后进入语言设置，选择 `English` 即可。

## 完全解锁版

完全解锁版会开放日本语、英语、德语、法语、意大利语、西班牙语、简体中文、韩语、
繁体中文、俄语和泰语。

1. 刷写完全解锁版。
2. 相机重启后进入语言菜单，对当前语言确认一次。
3. 再次打开语言菜单，确认已经显示全部 11 种语言。
4. 使用事先保留的官方 GXR 1.51 固件执行恢复。
5. 恢复后再次检查语言菜单，确认 11 种语言仍然保留。

完全解锁通常只需执行一次。确认解锁成功后建议恢复官方固件，不要反复执行语言
确认或长期保留修改固件。

## 刷写固件

1. 在相机中格式化一张容量不小于 64 MB 的 SD 卡。
2. 解压修改器生成的 ZIP。
3. 打开 `SD_ROOT`，把其中 29 个文件复制到 SD 卡根目录。复制的是文件，不是
   `SD_ROOT` 文件夹本身。
4. 安全弹出 SD 卡或相机磁盘，断开 USB，确认相机关机。
5. 按住 `+`，同时按住回放按钮 2–3 秒。
6. 出现更新确认画面后，用 Fn2 选择“是”，按 MENU/OK。
7. 等待更新完成并自动重启。更新期间不要断电、拔卡或拆卸相机模块。
8. 按所选模式完成上面的语言设置或解锁步骤。

遇到按键或菜单问题时，可以查看 Ricoh 官方更新手册：

- [GXR 固件更新手册（英文）](https://www.ricoh-imaging.co.jp/english/r_dc/download/firmware/docs/gxr_fwup_en.pdf)
- [GXR 固件更新手册（日文）](https://www.ricoh-imaging.co.jp/japan/dc/download/gxr/gxr_fwup_jp.pdf)

## 修改器如何工作

GXR 1.51 的程序、语言资源和字体中原本就有 11 种语言。日版机身的限制来自地区
设置，并不是缺少中文资源。

修改器先逐一核对官方升级包中的 29 个文件，只修改机身程序 `ilaunch3`。完成后会
重新计算固件内部校验，并核对修改结果的 SHA-256；其余 28 个升级文件保持不变。

英文替换版把 English 入口指向简体中文资源。完全解锁版调整语言确认路径，使机身
通过原厂设置写入流程保存开放地区值，因此恢复官方固件后仍可保留完整语言菜单。

更详细的分析程序、实验构建脚本、阶段报告和结构化结果见
[水水固件研究资料](研究资料/README.md)。研究目录不包含机身镜像、照片、序列号、
个人配置备份或官方固件原包。

## 从源码运行与打包

源码入口：

```bash

```
