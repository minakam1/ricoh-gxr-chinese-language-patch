# Ricoh GXR 1.51 简体中文补丁

这是经过真机验证的 Ricoh GXR 1.51 中文补丁。

刷写后语言菜单仍显示 `日本語 / English`：

- 选择 `日本語`：正常日文；
- 选择 `English`：实际显示简体中文。

## 下载

- `GXR_1.51_English_to_Simplified_Chinese.zip`
- `GXR_1.51_English_to_Simplified_Chinese.zip.sha256`

ZIP 的 SHA-256：

```text
27fc96f80746443a141c721a442b5620cadb1c41bc3eeaeec7f682350486eece
```

## 使用方法

1. 解压 ZIP。
2. 打开其中的 `SD_ROOT` 文件夹。
3. 将 `SD_ROOT` 里的全部 29 个文件复制到相机格式化的 SD 卡根目录；不要复制
   `SD_ROOT` 文件夹本身。
4. 按照 Ricoh GXR 官方固件升级方法执行更新。
5. 更新完成后进入语言设置，选择 `English`。

## 注意

- 仅用于 Ricoh GXR 机身固件 1.51。
- 使用满电电池；升级过程中不要断电、拔卡或拆卸相机模块。
